# Contribute a result someone else can check

Start with the README and the two supplied datasets. You can help without code by explaining one failure with the smallest fictional example that demonstrates it.

For a result report, include your method, the actual output, the expected output and one observation. Say whether you ran it, reviewed it by hand or have not tested it. If AI helped, say what you checked yourself. Do not present generated output as an experiment you ran.

For a code change, explain the behavior being corrected, include a small reproducer and run `node test.cjs`. Keep this kit dependency-free and usable offline. New cases should follow the documented fixture format; a new CSV parser or a live service integration is outside this exercise's scope.

For feedback on someone else's result, quote the relevant formula or rule, show a fictional input and explain the difference you observed. Be specific and respectful. Do not solicit votes, joins or paid services in result reports.

Use fictional data only. Do not include API keys, private customer records, personal contact details, screenshots of private accounts or account identifiers. No installation, Discord membership or personal-data submission is required to read the exercise.

Contributions may be discussed publicly. There is no guaranteed response time. The project's original files are under the MIT license; contribute only work you have permission to share under that license.
